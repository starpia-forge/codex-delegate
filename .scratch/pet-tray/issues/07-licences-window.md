# 07: Licences window

**What to build:** The tray menu gains **Licences**. It opens a normal window the user can focus, scroll, resize and close, or brings that window to the front if it is already open. The window shows codex-delegate's MIT licence, the fan-art notice and the crate notices, and it works while pets are hidden. Its title, headings and empty states follow the display language live. The licence texts stay in their original English.

**Blocked by:** 03, 05, 06

**Status:** ready-for-agent

Spec: `.scratch/pet-tray/spec.md` (Pet shell: licences window; Licence notices)

- [ ] The licences window is a second webview created on demand:
  - It is decorated, focusable and resizable, and has a taskbar entry.
  - It doesn't follow the strip's click-through, topmost or fullscreen handling, and is not capture-excluded.
  - It is destroyed when closed.
- [ ] The window has its own minimal capability: event listening plus the `messages` and `notices` commands. The strip's capability and the CSP are unchanged.
- [ ] The window subscribes to language events before reading the current language and catalogue.
- [ ] The embedded development stub is shown as "generated by the release build".
- [ ] The catalogue test covers the window's message ids.
- [ ] Manual:
  - The window opens and focuses, scrolls, resizes and closes, and works while pets are hidden.
  - Clicking Licences twice keeps one window.
  - It opens in the right language after a switch, and follows a switch made while it is open.
  - Opening it never makes the strip block clicks.
